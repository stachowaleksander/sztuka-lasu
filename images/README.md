# Zdjęcia prac – Sztuka Lasu

Każdy cykl ma swój folder, a w nim:
- `duze/` – wersje do pokazania na stronie (maks. 1600 px),
- `miniatury/` – małe wersje do siatki galerii (maks. 600 px).

Z plików usunięto metadane EXIF (np. model telefonu, ewentualne dane lokalizacji).

`prace.json` to katalog prac. Tytuły są robocze – do zastąpienia prawdziwymi.
Puste pola (gatunek drewna, skąd drewno, wymiary, rok, dostępność, opis) uzupełniamy z mamą.
Pole `oryginalny_plik` pozwala odnaleźć zdjęcie źródłowe.
